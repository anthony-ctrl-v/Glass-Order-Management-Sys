# Documentation

This directory contains the project's private, repository-based wiki. It provides a free alternative to a GitHub Wiki while the repository remains private.

## Wiki Pages

- [Home](home.md) — Research question and project overview
- [Log](log.md) — Dated weekly entries: attempts, outcomes, and decisions
- [Design](design.md) — Pipeline rationale and rejected alternatives
- [Results](results.md) — Measurements linked to commits or tags
- [Reading](reading.md) — Papers and their contributions
- [Appendix](appendix.md) — Side research and off-main-line investigations

Add focused information to these pages as the system evolves, and keep it consistent with the implementation and decisions approved by the project team.
